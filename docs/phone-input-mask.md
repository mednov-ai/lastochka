# Маска российского телефона

25.10.2026 реализовано `enforce-phone-input-mask`. Общий телефон гостевой заявки и
черновика оплаты показывает неизменяемый `+7`, десять национальных позиций и
автоматические разделители: `+7 900 123-45-67`. Незанятые позиции маски видимы
во время ввода; подчёркивания не являются значением поля.

## Реализация

`frontend/app/ui/phone-input.tsx` объединяет постоянный префикс, один доступный
input и декоративный остаток маски. Префикс не входит в редактируемый текст;
удаление, очистка и выделение не могут изменить его. Каретка сопоставляется с
индексами цифр, поэтому замена и удаление рядом с пробелом/дефисом работают в
месте правки. Beforeinput и резервные input/change поддерживают мобильный ввод;
paste/cut и история цифр/выделения обеспечивают вставку, вырезание и undo/redo.

`phone.ts` различает десять национальных цифр и одиннадцать цифр с кодом 7/8.
Полная вставка нормализуется; лишние цифры и посторонний текст отклоняются целиком.
Десятизначные номера, начинающиеся с 7/8, не теряют первую цифру. Пустые позиции
не заполняются нулями. Обычная одиннадцатая национальная цифра не добавляется.

Внутреннее поле `phoneNational` преобразуется в прежний API `phone`.
Серверный action проверяет национальную часть до обращения к backend и сохраняет
поддержку старого полного поля `phone` для вкладок до обновления; противоречивые
поля отклоняются. Ошибки API по-прежнему связаны с телефоном. RussianForm даёт
точную русскую причину неполного номера для кнопки и Enter и снимает устаревшую
ошибку после исправления. API/генерируемые DTO, backend, миграции и данные не менялись.

Без JS доступны постоянный код страны, подсказка и обязательный input ровно десяти
цифр с серверной отправкой; автоматические разделители и распознавание полного
вставленного номера относятся к режиму с JS. Ранний ввод до гидратации сохраняется.
Общая рамка фокуса сохраняет зазор подписи и не меняет геометрию при фокусе.
При сильно увеличенном тексте национальная часть может прокручиваться внутри
input, не создавая горизонтальной прокрутки страницы; код страны остаётся видимым.

## Проверки

- **17** случаев разбора/оформления/сборки формы: национальные и полные номера,
  разделители, начальные 7/8, неверный код, буквы, избыток, прежний и двойной набор полей.
- **32/32** целевых browser-сценария Chromium/WebKit × en-US/ru-RU × 375/1440:
  непрерывный ввод, незанятые позиции, удаление/выделение/замена, каретка, undo/redo,
  полная/частичная вставка, отказ переполнения, автозаполнение через input/change,
  русская проверка кнопкой и Enter, ошибки черновика, SSR и ранний ввод.
- **32/32** регрессионных сценария форм/входа/панелей. Измерение составного
  телефона учитывает общую рамку фокуса. Восемь настоящих no-JS отправок на
  изолированной БД прошли; собственные заявки/очередь/replay удалены.
- **32/32** регрессионных сценария мобильного меню, гостя/ADMIN, навигации,
  клавиатуры, no-JS, touch/reduced-motion и увеличенного текста.
- Семь интеграционных групп подтвердили настоящие JS/no-JS отправки,
  `+79001234567` в БД, отказ неверных серверных полей, совместимость старого
  поля с начальной 8, самостоятельную проверку прямого API, создание черновика
  из заявки, предзаполнение при редактировании и сохранение нового контакта без
  изменения исходной заявки. Точечная очистка собственных fixtures выполнена.
- Дополнительно проверены отказы SSR action 400/409/503 при отключённом транспорте:
  телефон, остальные значения и исходный commandKey сохраняются.
- Ширины 320/375/390/430/768/1440, текст 200%, доступные имена и связанная ошибка,
  reduced-motion, отсутствие переполнения. Скриншот формы 375 px просмотрен.
- Node 24: check:ui-language, typecheck, production build и Prettier затронутых
  файлов прошли. Новой runtime-зависимости нет. Изменены ровно семь продуктовых
  frontend-файлов; backend/API не изменены относительно снимка до начала работ.

Первый прогон обнаружил выход декоративного остатка маски при увеличении текста;
ограничение слоем национальной части исправлено до приёмки. Старый no-JS тест
передавал полный номер в теперь национальное поле; обновлён на десять цифр,
сохранена настоящая отправка. Проверки не ослаблялись до проверки только CSS-классов.

Доказательства: `artifacts/phone-mask/`: `local-tests.log`, `forms.log`, `menu.log`,
`local-integration.json`, `action-failures.json`, `source-scope.json`, снимки в
`browser/`, `form-regression/`, `menu-regression/`, журналы сборки/типов/форматирования.

Физический iPhone, экранная клавиатура Safari и VoiceOver отдельно не проверялись.
Программная проверка autofill не заменяет реальную адресную книгу устройства;
удалённый CI не запускался. Публичная поставка описывается отдельным отчётом.
