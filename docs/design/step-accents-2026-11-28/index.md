# Подсветка шагов в разделе «Наш подход»

В локальной сборке от 28 ноября 2026 года лента и летящая ласточка убраны со всей главной. При движении вниз номера загораются по очереди. Если остановиться между вторым и третьим шагами, 01 и 02 остаются бирюзовыми, а 03 — светлым. При обратной прокрутке подсветка гаснет в обратном порядке.

| Локальная проверка через Playwright CLI | Снимок после включения 02 |
| --- | --- |
| Chromium, 1440 × 900, три шага в строку | [Компьютер](desktop-chromium.png) |
| WebKit, 375 × 812, три шага в колонку | [Телефон](mobile-webkit.png) |

В обоих браузерах при ширине 320 CSS px горизонтальное переполнение составило 0 px. В дереве доступности каждый номер читается один раз. Охристые точки оформлены средствами CSS, пропускают нажатия и остаются на месте при включении номера.

Проверки выполнялись на локальной production-сборке frontend с изолированным API и демонстрационным содержимым. Мобильные размеры проверены в браузерах на компьютере.

Набор `playwright.ribbon.config.ts` прошёл целиком: 68 проверок в Chromium и WebKit. Проверены обе стороны прокрутки, перестройка ряда в колонку, обновление с якорем, статический режим без JavaScript, смена системной настройки движения и доступ к форме заявки. Сборка, TypeScript и проверка языка интерфейса прошли. Строгая валидация OpenSpec прошла для 31 элемента. Порядок синхронизации двух изменений проверен отдельно на временной копии спецификаций.
