# Вход администратора и выход из кабинета

Локальная реализация изменения `clarify-admin-entry-and-logout`, 28 октября 2026 года. Это не отчёт о поставке: тестовый сервер и production в этой работе не изменялись.

В подвале гостю предлагается вход, вошедшему ADMIN — кабинет, пользователю с временным паролем — обязательная смена. Действие перед переходом заново проверяет сессию; при ошибке предлагает повтор. Прямой адрес входа на сервере проверяет сессию конкретного запроса и не кешируется общим кешем. Повторное подтверждение пароля в безопасности осталось отдельным сценарием.

Кнопка «Выйти» находится в общей навигации всех разделов кабинета и на странице обязательной смены пароля. Используется прежний CSRF-защищённый серверный выход. Ошибка не выдаётся за успех; редактор сохраняет ввод до решения пользователя и подтверждения выхода. Сохранён существующий порядок очистки контекста календарной команды при успешном выходе.

## Локальные проверки

- 36 целевых browser-сценариев: Chromium/WebKit × 320/1440 px, русский/английский locale, вход, выход, временный пароль, две вкладки, задержанные ответы, ошибка выхода и несохранённые изменения. Дополнительно повторены сценарии реального повторного подтверждения пароля и отзыва ограниченной сессии через штатное назначение временного пароля.
- 24 регрессионных сценария публичной навигации и расписания: Chromium/WebKit × ru-RU/en-US × 375/1440 px, включая no-JS, узкие экраны и увеличение текста. На отдельной локальной базе выполнена настоящая гостевая заявка без JavaScript.
- Два сценария переключения локального frontend с образа 0.14.0 на новую production-сборку с сохранёнными старыми ресурсами: прежняя вкладка и ADMIN-сессия пережили переключение, переход работал в Chromium и WebKit с эмуляцией касания. Это локальная проверка, не свидетельство серверного развёртывания.
- Отдельно проверены гостевая, полная и ограниченная сессии без JavaScript, независимые browser-контексты, точные пути внутри `/lastochka`, а также отказ проверки `/auth/me`: HTTP 503 с `private, no-store` без формы входа. Истечение сессии моделировалось анонимным ответом; реальное ожидание 30-минутного тайм-аута не выполнялось.
- `npm run typecheck`, `npm run build` (включает `check:ui-language`), строгая проверка OpenSpec и `git diff --check` прошли. Снимки и трассы проверок — в локальном игнорируемом `artifacts/admin-entry/`.

Проверки выполнялись на собственном временном PostgreSQL и отдельном backend, без изменения исходных аккаунтов и данных сервера. Физические устройства, внешние браузеры, удалённый CI и серверная приёмка не проверялись.
