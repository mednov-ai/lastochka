# Исправление расписания и окна кабинета

## Маршруты и состояния

| Маршрут | Исходное поведение | Целевое правило изменения |
| --- | --- | --- |
| Создание отдельного занятия | Новое занятие должно начинаться в будущем; сначала создаётся DRAFT | Без изменения |
| Изменение отдельного занятия, включая прежний PUT | Запрещено после начала или при отмене; проверяются версия, поля и ресурсы опубликованного занятия | Неотменённое занятие можно исправить независимо от времени; сохраняются проверка версии, поля, ресурсы, аудит и исключение серии |
| Чтение/сохранение/отбрасывание/публикация черновика и восстановление из истории | Чтение/история доступны; изменение черновика ограничено будущими OPEN/CLOSED | OPEN/CLOSED независимо от начала; CANCELLED — просмотр и история без команд правки |
| Действия отдельного занятия | После начала запрещены публикация DRAFT, изменение приёма и отмена | Публикация исправленного DRAFT разрешена, прочие действия после начала по-прежнему запрещены |
| План и публикация серии | Новые даты допустимы с понедельника текущей недели МСК; начавшиеся существующие вхождения сохраняются | Правило создания и защита истории при массовой правке без изменений; индивидуальная правка создаёт исключение |
| Публичный список и заявка | Новая привязка только к будущему OPEN; запись заявки и команды сериализуются | Правила без изменения; при изменении времени проверяется итоговое состояние, снимки старых заявок сохраняются |

Все административные команды используют идентификатор администратора, CSRF, идемпотентный ключ и общий серверный замок. Изменение поведений API аддитивно; новые типы запросов или схема базы не предполагаются. Активная дельта `clarify-recurring-schedule-time-conflicts` содержит прежний запрет индивидуальных исправлений и должна быть синхронизирована раньше дельты настоящего изменения, которая его заменяет; правило добавления новых дат серии сохраняется.
