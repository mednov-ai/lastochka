## Что изменено

До1000 px общая шапка показывает кнопку «Меню» и раскрывает пять обычных ссылок:
«О занятиях», «Форматы», «Тренер», «Контакты», «Расписание». Список расположен
в потоке sticky-шапки; он прокручивается при нехватке высоты. Логотип и
«Записаться»/«Кабинет» сохраняются. На320–430 px кнопка меню занимает вторую
строку, на431–1000 px помещается в одну строку с остальными действиями.
Desktop-навигация остаётся прежней.

Небольшое локальное состояние находится в `MobileNavigation`, а не в корне
приложения. Один набор адресов/русских подписей используется desktop, мобильным
списком и no-JS вариантом. Новых зависимостей, запросов API или обработчиков
прокрутки нет. `useHeaderOffset` учитывает изменённую высоту и отдельно измеряет
высоту управляющей части для ограничения списка.

Меню закрывается после выбора, включая повтор текущего hash, при смене маршрута,
переходе на desktop, Escape, активации основного действия, клике вне шапки и
выходе клавиатурного фокуса. Escape возвращает фокус к кнопке; внешний клик
и навигация сохраняют естественную цель. Закрытие снаружи происходит после
активации, чтобы изменение высоты не сдвинуло ссылку между pointerdown и click.
Учтён WebKit: после нажатия кнопки указателем фокус может остаться на body;
Escape работает и в этом состоянии, не перехватывая фокус другого dialog.

Без JavaScript используются `details/summary` в noscript. Включённый JS
сохраняет noscript скрытым, включая содержащийся в нём текст HTML. Статические
ссылки к якорю той же страницы не закрывают список автоматически: посетитель
закрывает его переключателем, браузер сохраняет целевой раздел в видимой области.
Для этого резервный CSS-отступ рассчитывается на закрытую шапку. React-разметка
исходного HTML и гидратация проверены на production-сборке.

## Поставка и синхронизация спецификаций

Отдельная поставка завершена frontend0.9.8:64 публичных сценария и10 повторов
WebKit прошли. По результатам приёмки включена полная карта маршрутов при загрузке,
совместимый ответ прежним lazy-клиентам и disabled SSR-кнопки до гидратации.
Последняя локальная проверка после этих уточнений подтвердила32 различных
сценария меню (30 в основном прогоне и8 в повторном клавиатурном),48 шапки/темы
и32 полей. Включённое ожидание готовности JS сохраняет проверки реального фокуса,
навигации и русских ошибок. Откат — совместимый frontend0.9.5 без восстановления БД.

Изменение не архивировано. Требование «Постоянная компактная мобильная шапка»
сейчас введено активной дельтой pin-mobile-header, а не основными specs. Поэтому
CLI сообщает, что прямое архивирование новой MODIFIED-дельты пока невозможно.
Сначала следует синхронизировать/архивировать pin-mobile-header, затем это
изменение, сверив конечное требование целиком. Существующие архивы не изменялись.
