# Скачок прокрутки после выбора недели

## Воспроизведение до исправления

Локальная разработческая сборка с `polish-api` fixture, Chromium, 1440×900 CSS px. После нажатия «Следующая неделя» кнопка оставалась в фокусе, шапка была высотой 61 px, `scrollY` около 3106. При последовательной прокрутке колесом вверх страница доходила до 0–42 px и возвращалась примерно к 2740 px; эффект повторялся. Сетка недели уже загрузилась до прокрутки.

Инструментирование вызовов показало `scrollIntoView` для той же кнопки из `reveal`, вызванного измерением шапки в `header-offset.ts`; активный элемент не менялся. На границе состояния шапка разворачивается, `ResizeObserver` повторно запускает измерение и раскрывает старый фокус, а последующая компактная шапка снова меняет размер. Вызовы `scrollBy` из отложенной коррекции также присутствовали. Загрузка расписания или смена фокуса не требуются для воспроизведения.

## Исправление и проверка

Измерение панелей больше само по себе не возвращает страницу к старому фокусу; новый фокус по-прежнему раскрывается, а при изменении окна корректируется только элемент, оставшийся на экране. Колесо, движение пальца и клавиши прокрутки отменяют ожидающие коррекции. Фокус кнопки и выбранная неделя не сбрасываются.

- До исправления новая проверка в Chromium 1440×900 не смогла удержать страницу в начале; после — основные сценарии на 1440×900 и 375×812 прошли в Chromium и WebKit. `playwright-cli` отдельно подтвердил `scrollY=0`, сохранённые фокус и неделю на обоих размерах в Chromium.
- Новые тесты также проверили предыдущую и текущую недели, дату, ближайшее занятие, пустую неделю и задержку ответа, Tab/Shift+Tab и изменение размера; 10/10 проверок в двух движках прошли. Существующий набор афиши и шапки: 92/92.
- Проверены якорь, формы, закреплённые панели и возврат фокуса из окна входа на фикстуре. Расширенный набор: 26/28. Известная проверка WebKit без JavaScript не проходит из-за перекрытия фокуса на малом экране. Вторая проверка состояния администратора нестабильна из-за встречной навигации: по одному сбою из трёх повторов как с исправлением, так и с исходным `header-offset.ts`.
- `npm run typecheck`, `npm run build` и встроенная проверка языка прошли. Правила Web Interface Guidelines рассмотрены для изменённой логики фокуса: отклонений в затронутом коде не найдено; перечисленные выше ограничения браузерных проверок сохраняются.

Физические устройства, реальная экранная клавиатура, экранные дикторы, удалённый CI и стенды не проверялись. Мобильные размеры проверены в автоматизированных браузерах; реальный сенсорный жест отдельно не проверен. Production и test не обновлялись.
