## Откат

Подготовлен и загружен `lastochka-frontend:0.10.1-schema14` — прежний принятый интерфейс с явной совместимостью схемы14. Он используется **только с backend0.11.0**, который сохраняет ограничения временных паролей. Прежние постоянные ADMIN работают, а для завершения смены временного пароля требуется вернуть новый интерфейс. Gate согласованной пары и сохранённый старый клиент проверены.

Возврат оформления: адресно заменить только FRONTEND_IMAGE на этот тег в защищённом env, выполнить штатный Compose `up -d --no-deps --wait frontend` с прежними project/env/compose, затем пересоздать собственный proxy для DNS и проверить HTTPS/сохранность. BACKEND_IMAGE и БД не менять. Возврат новой формы —FRONTEND_IMAGE `lastochka-frontend:0.11.0` тем же способом.

**backend0.10.0 после включения временных паролей не является безопасным откатом.** Backend допускает только исправление вперёд либо другую проверенную сборку с PASSWORD_LIFECYCLE_V1. Старый dump поверх новых заявок запрещён; disaster restore требует отдельной процедуры и новой внешней ADMIN_ACCESS_GENERATION.
