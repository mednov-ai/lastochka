После первой выкладки на текущей неделе строка «6–7 лет» показывала «Набираем группу»: её занятия во вторник и четверг уже прошли, а публичный API намеренно отдаёт только будущие занятия. По решению пользователя исправлено во frontend, backend не менялся. Вместе с выбранной неделей загружается следующая. Пустая строка показывает «Ближайшее занятие: вторник, 17 ноября, 17:00» и ссылку-кнопку «Показать следующую неделю». «Набираем группу» остаётся только у направлений без занятий и на следующей неделе. При сбое этой загрузки выводится нейтральное «На этой неделе занятий нет». Текст на телефоне: «В остальные дни этой недели занятий нет».
