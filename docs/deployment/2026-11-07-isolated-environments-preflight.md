# Подготовка двух окружений — 7 ноября 2026

Это частичная read-only проверка, а не поставка. Новые базы или окружения не создавались.

- Новый сервер: Ubuntu 24.04 LTS, 1 vCPU, 961 MiB RAM, swap 1 GiB. После установки Docker 29.1.3 и Compose 2.40.3 из репозитория Ubuntu (службы активны) доступно около 414 MiB RAM, `/` 19 GiB, свободно около 14 GiB. SSH и Fail2ban активны, Nginx и контейнеры приложения пока не установлены.
- DNS на момент проверки: `lastochka-gym.ru` и созданный по решению пользователя `test.lastochka-gym.ru` указывают на новый сервер; `play-and-say.ru` — на прежний адрес. Тестовый сайт и HTTPS ещё не запущены.
- Исторический замер одной копии preview после старта — около 519 MiB, без нагрузочной приёмки (см. `2026-10-19-preview.md`); две текущие версии, обновление и backup не измерялись. Эти цифры нельзя использовать как измерение нового релиза или гарантию размера тарифа.
- На локальном Docker Desktop проверены изолированные контейнеры с отдельной синтетической БД без публикации портов: backend 0.19.3-flat (amd64 под эмуляцией), frontend 0.19.1 и PostgreSQL 17.6. При лимитах backend 384 MiB / frontend 128 MiB / PostgreSQL 128 MiB все службы достигли health, в покое заняли около 379 / 69 / 59 MiB; при лимите backend 256 MiB и MaxRAMPercentage=40 процесс был завершён по OOM (137). Эта оценка не является измерением на VPS, нагрузкой или проверкой резервирования. Созданные только для эксперимента контейнеры, сеть и пустой тестовый том удалены по метке проекта.
- На новом VPS те же версии запущены с отдельной синтетической БД, без публикации портов и без реального банка. При лимите backend 320 MiB службы достигли health и использовали около 310 / 91 / 65 MiB, swap хоста — 416 MiB. Повтор с backend 256 MiB также достиг health и показал около 253 / 63 / 76 MiB, swap хоста — 405 MiB; запас backend около 3 MiB. Это не нагрузочное испытание и не подтверждение работоспособности двух зон. После каждого прогона созданные только для него контейнеры, сеть и пустой том удалены по метке; SSH, Fail2ban и Docker активны. Образы приложения и PostgreSQL сохранены на VPS.
- После увеличения тарифа и перезапуска Ubuntu видит 1,9 GiB RAM и 1 vCPU. Два изолированных синтетических проекта с отдельными базами и без host-портов одновременно достигли health: суммарно около 911 MiB контейнерной памяти, около 885 MiB доступной памяти хоста и 298 MiB занятого swap в момент измерения. Лимиты backend — 320 и 256 MiB; занято около 311 и 251 MiB соответственно. Оба тестовых backend близки к пределам, запуск второго занял около 96 секунд. Реальная нагрузка, backup, сбои и выпускаемые окружения не проверены. По завершении удалены только синтетические проекты и их тома, службы SSH/Docker/Fail2ban активны.
