Поле размера группы отсутствует в общей форме создания и изменения постоянного расписания; ранее сохранённое значение при изменении правила остаётся прежним. Backend не перезапускался, миграции и операторские изменения базы не выполнялись; production не выпускался.

Frontend собран в отдельной копии из `develop` на основе `6e69c9a025016f9b128dfa9689f17017faa83b57` с адресным изменением компонента. Параллельные незакоммиченные изменения Альфа-Банка в образ не вошли. Образ `linux/amd64` — `sha256:6bb85ff39127fe26e25db67299ef0f247e1f030fdb84306565f9bb7ddd4282c3`, архив SHA-256 `533596c0e3957234307eec68205a3856ef9a5d5b522617ff76e0945a95d6b1a2`. Заменён только frontend test с сохранением его IP. Контейнеры test backend, PostgreSQL, proxy/gate и все пять контейнеров production сохранили идентификаторы, образы и время запуска; конфигурация production не менялась.

На HTTPS проверены frontend health и пять возрастных направлений; форма проверена в `playwright-cli` на desktop и mobile с подставными авторизацией и данными API, без публикации занятий.
