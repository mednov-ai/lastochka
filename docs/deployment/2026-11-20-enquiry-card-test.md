# Завершённая карточка заявки на test

20 ноября 2026 года на test обновлён frontend до `0.25.1-enquiry-card-test-20261120`. Источник — коммит `0818c801be1d14fd86d528a9133e87c2d61ff030` ветки `develop`. SHA-256 образа — `sha256:d136e53904cdc0c987dd3bafd2bdb31f10e783cc1c9dabaaeb6a507976e3fef4`. Backend продолжает работать на `0.25.0-permanent-week-test-20261119`, БД — V32.

При просмотре исторической заявки сохраняется исходный текст пожелания. Статусы Telegram и браузерных уведомлений отображаются независимо. Успешный повтор Telegram сохраняет видимое предупреждение о сбое push.

Защищённая операторская процедура сверила окружение test, Compose, схему, предыдущие образы и том ресурсов. Заменён только frontend. Сверены прежние IP, идентификаторы и время запуска остальных десяти контейнеров. HTTPS /healthz и /readyz вернули новую версию. Файл кабинета `admin-CvFZSlqW.js`, указанный на странице /admin/requests, совпал с содержимым образа по SHA-256 `811f893d446982cdd70c718b9c2584398e07d5e07839ff424d45d141af8e5e10`. Все 537 ресурсов предыдущих сборок доступны по HTTPS и совпали по SHA-256. Публичная афиша вернула пять возрастных категорий и ноль опубликованных интервалов. Принят TLS 1.2, соединение с обязательным TLS 1.3 отклонено.

Проверены Chromium и WebKit на 320, 390 и 1440 CSS px, фокус, длинный текст при увеличении 200%, исторические и регулярные пожелания, частичный отказ доставки, права и переход к незаписанному черновику. Авторизация и ответы кабинета на test были подставлены. Реальный путь от заявки до карточки отдельно пройден в локальной ADMIN-сессии. В первом прогоне регрессии прошли восемь из десяти сценариев. Два сценария WebKit превысили тайм-аут 30 секунд: обработка запоздавшего ответа при смене заявки и доступ сотрудника к созданию оплаты. При отдельном последовательном повторе оба прошли.

Для возврата подходит предыдущий frontend `0.25.0-permanent-week-test-20261119` на той же схеме. Предыдущая конфигурация сохранена в закрытом каталоге выпуска на сервере. Фактический откат после выпуска не выполнялся.
