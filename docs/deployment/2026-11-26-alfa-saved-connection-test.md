# Проверка сохранённого подключения Альфа-Банка на test

26 ноября в 20:11 МСК в кабинете администратора на test нажата кнопка «Проверить подключение». В полях тестового логина и пароля отображались восемь точек. Оба поля были пустыми, новые значения не вводились. Браузер отправил `POST /api/v1/admin/alfa-config/connection/check` без тела. Сервер обратился к тестовому шлюзу Альфа-Банка, сверил номер, сумму, валюту и оплаченный статус контрольного заказа. Кабинет получил HTTP 200, `outcome=CONFIRMED` и `checkedAt=2026-11-26T17:11:31.345738987Z`.

На экране появилось «Подключение подтверждено. 26 нояб. 2026 г., 20:11 МСК». Дата изменения реквизитов осталась 13 ноября, 16:14 МСК. Количество записей и контрольные суммы содержимого пяти таблиц совпали до выкладки и после проверки. Сверены настройки Альфа-Банка, версии реквизитов, выбор шлюза, банковские попытки и платежи. Проверку выполнили в Chromium с реальными API сайта и банка. Один результат просмотрен на ширинах 1440 и 375 px.
