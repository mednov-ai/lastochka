# Мобильное меню — поставка frontend 0.9.8

24.10.2026 по поручению «Deploy» опубликован **frontend0.9.8** на
https://play-and-say.ru/lastochka/. Backend **0.9.0**, PostgreSQL **V12**.
До1000 px доступны пять пунктов раскрывающегося меню с корректными переходами,
закрытием, фокусом и no-JS вариантом. [Локальная реализация](../mobile-header-section-menu.md).

## Исправления по результатам публичной приёмки

Первый кандидат0.9.6 не принят: WebKit воспроизводимо оставлял пустой Outlet
при клиентском переходе из заявки на главную, хотя HTTP-запросы были успешны.
В trace наблюдались конкурентные запросы lazy discovery. Выполнен настоящий
frontend-only откат на0.9.5; readiness и сохранность данных проверены.

В0.9.7 включена штатная полная карта маршрутов `routeDiscovery.mode: initial`.
Код страниц продолжает загружаться отдельно. Для прежних lazy-клиентов endpoint
`/lastochka/__manifest` возвращает204, `X-Remix-Reload-Document` и no-store:
клиент может обновить документ вместо получения404 при обнаружении маршрута.

Итоговый0.9.8 дополнительно держит SSR-кнопку JS-меню отключённой до подключения
обработчиков, чтобы раннее нажатие не терялось. No-JS summary работает независимо.
Сценарии явного клавиатурного фокуса и модального входа ожидают готовности JS;
до неё ссылка входа штатно ведёт на прямую страницу. Кандидаты0.9.6/0.9.7
не являются принятой конечной поставкой и не рекомендуются для отката.

## Откат и OpenSpec

Стабильный совместимый frontend0.9.5 сохранён. Штатный откат: заменить только
FRONTEND_IMAGE на `lastochka-frontend:0.9.5`, выполнить прежнюю Compose с
`up -d --no-deps --wait frontend`, затем пересоздать собственный proxy.
Backend/V12 и новые данные не менять, dump поверх актуальной БД не восстанавливать.
Операторская процедура итоговой поставки предусматривает тот же стабильный
frontend0.9.5 при ошибке переключения.

`add-mobile-header-section-menu` выполнено8/8 и поставлено, не архивировано.
Перед будущим архивированием синхронизировать pin-mobile-header, затем новую
MODIFIED-дельту, чтобы сохранить уточнённые пределы высоты. Архивы не менялись.
