# Тестовая настройка Альфа-Банка — браузерные снимки

Снимки выполнены 12.11.2026 на `https://test.lastochka-gym.ru/` после выпуска frontend 0.20.9. Это реальные захваты страницы в эмуляции Chromium и WebKit; для сценариев аккаунта и банка в браузере подставлены ответы API, реальные реквизиты не вводились и действия на сервер не отправлялись. Поле отсутствует также в сохранённой реальной ADMIN-сессии после обновления страницы. Физические устройства не проверены.

Снимок карточки может содержать закреплённые шапку и подвал страницы: Playwright прокручивает карточку для захвата, но фиксированные панели остаются в окне. Доступность сфокусированных элементов дополнительно проверена программно при 200% размера текста. На одном предыдущем прогоне WebKit немедленная проверка точки фокуса не прошла; при ожидании завершения прокрутки повторные проверки локального образа и HTTPS прошли.
