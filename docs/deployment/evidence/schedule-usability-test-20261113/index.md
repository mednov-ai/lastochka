- [Кабинет на компьютере](admin-desktop-fixture.png) и [телефоне](admin-mobile-fixture.png): настоящий опубликованный frontend с подставными сессией, правилом и API; запросы изменения заблокированы. Проверены отображение расчётного занятия и окно только для чтения.
