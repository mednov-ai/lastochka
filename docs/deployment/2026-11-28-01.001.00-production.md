У каждого backend собственные пути к ключам Альфа-Банка и VK. На запущенных контейнерах проверены отдельные монтирования только для чтения и различие значений между зонами. Также проверены пароль подключения приложения к PostgreSQL, пароль PostgreSQL и файлы защиты PIN. Каталоги резервных копий банковских ключей раздельны, ключ каждой зоны совпал с собственной защищённой копией. В production нет монтирования тестового Callback. На время переноса процесс с полномочиями root читал оба банковских ключа. Операторский root на VPS сохраняет технический доступ к файлам обеих зон.

Эффективные UID приложения проверены по процессам на хосте. Java работает как 10001, frontend Node.js как 1000. Оба контейнера запущены без privileged и без Docker-сокета. Демон Docker и главные процессы прокси Nginx работают как root, рабочие процессы Nginx — как 101.
