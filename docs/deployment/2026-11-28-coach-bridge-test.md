# Портрет Паргева и мостик между шагами на test

28 ноября 2026 года опубликован frontend `0.27.22-coach-bridge-test-20261128`. Предыдущая версия скрывала портрет маской до срабатывания наблюдателя при прокрутке. Теперь браузер получает адрес фотографии из исходного HTML и начинает загрузку заранее с низким приоритетом. Размеры заданы до загрузки. Готовая фотография видна с первого края при прокрутке к тренеру.

В «Нашем подходе» один охристый мостик следует за прокруткой между номерами и возвращается по той же дуге при движении вверх. На компьютере путь проходит над цифрами, на телефоне — слева от карточек. При системном уменьшении движения и без JavaScript шаги читаются в статическом виде.
