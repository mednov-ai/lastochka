# Подсветка шагов на тестовом сайте

28 ноября 2026 года на [тестовой главной](https://test.lastochka-gym.ru/#approach) опубликован frontend `0.27.21-step-accents-test-20261128`. Лента с летящей птицей убрана. При прокрутке раздела «Наш подход» загораются номера 01, 02 и 03. Охристые точки рядом с ними неподвижны.

## Проверка на стенде

В Chromium и WebKit при 1440 × 900, 375 × 812 и 320 × 667 число подсвеченных номеров при прямой и обратной прокрутке последовательно составило 0, 1, 2, 3, 2, 1, 0. На desktop и при 375 px после перезагрузки с якорем сохранилась подсветка первых двух номеров. На всех трёх размерах горизонтальное переполнение составило 0 px. При системном уменьшении движения плашки отображались без смещения. Мобильные размеры проверены в эмуляции, API стенда использовался без подмены.
