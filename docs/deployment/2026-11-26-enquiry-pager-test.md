# Пагинация одной страницы заявок на test

26 ноября выпущен frontend `0.27.15-enquiry-pager-test-20261126`. В реальной сессии администратора на тестовом сайте над списком из четырёх заявок виден диапазон «1–4 из 4». Под списком появился блок «Заявки: страница 1 из 1» с недоступными кнопками «Назад» и «Далее».

Ревизия изменения в `develop` — `6cee276`, исходная ревизия — `b3e1bb7`. К работающему frontend 0.27.14 применены изменения компонента Pager и его вызова в реестре заявок. Оплаты используют прежнее значение параметра. Идентификатор нового образа — `sha256:a0121e99bb7986171136701853400476338226c6b1f6f7efbdd22a0038d97106`, опубликованный манифест — `manifest-a728c7ad.js`.

Проверки типов, русского текста и сборки прошли. На локальной сборке прошли все 10 проверок реестра и карточки из `admin-enquiry-review.spec.ts`. В браузерном сценарии использованы наборы из 0, 4, 25, 26 и 56 заявок, переходы вперёд и назад, восстановление страницы по адресу и повтор после ошибки. Пустой список показывает «Заявок пока нет». Начиная с 26-й заявки доступна вторая страница.

После выкладки frontend прошёл проверку здоровья. Контрольные суммы 591 прежнего ресурса совпали. Проверены 11 остальных контейнеров, конфигурации Nginx и ограничение TLS 1.2. [Снимок на тестовых данных](evidence/enquiry-pager-20261126/desktop.png).
