# Перезагрузка главной и мобильный подвал на test

27 ноября 2026 года на test выпущен frontend `0.27.16-landing-scroll-test-20261127-r2`. Публичная проверка здоровья вернула эту версию и состояние UP. Проверки выполнены через HTTPS с реальным API тестового сайта.

## Перезагрузка

До выпуска в WebKit при 1440 × 900 заголовок «Маленькие шаги. Большая уверенность.» переместился с 587 до 357 CSS px от верхнего края окна после обновления страницы с якорем `#approach`. Страница прокрутилась вниз на 230 px.

После выпуска в Chromium и WebKit при 375 × 812 и 1440 × 900 выполнены 24 обновления с якорем. Дважды подряд обновлялись страница выше раздела, ниже раздела и в самом начале. Во всех случаях отклонение составило 0 CSS px. Обновление без якоря и возврат из формы заявки дали тот же результат. При открытии прямой ссылки и повторном выборе «О занятиях» клавишей Enter заголовок был виден ниже шапки.

При дополнительной проверке WebKit на 1769 × 1230 после ручной прокрутки заголовок остался на высоте 580,625 CSS px. В течение 39 измеренных кадров его координата была постоянной. ## Мобильный подвал

В Chromium и WebKit проверены главная и форма заявки на ширинах 375, 700, 701 и 1440 CSS px с JavaScript и без него. Во всех 32 сочетаниях доступны шесть ссылок, у каждой область касания высотой не менее 44 CSS px. Переключатель отсутствует, горизонтального переполнения нет. До 700 px включительно подвал прокручивается вместе со страницей, с 701 px он закреплён. Проверены видимый клавиатурный фокус и переход касанием к пользовательскому соглашению. Телефонный экран эмулировался. ## Состав и проверка выпуска

Исходная ревизия рабочего каталога `develop` — `3fac2a448dbaee917e9a87989bbbf3eea15a4f9a`. Сборка использовала сохранённые исходники действующего frontend 0.27.15 и локальные правки OpenSpec к пяти файлам приложения. Это сохранило ранее выпущенные версии интерфейсов кабинета. Образ linux/amd64 — `sha256:05614842865d6847ff4c4902c64507a1bcb63611e2ca40f13daf88552b9d4023`. Контрольная сумма манифеста `manifest-97c3eea9.js`, полученного по HTTPS, совпала с локальной.

Первый кандидат запустился с недоступными пользователю node файлами сборки. Автоматический откат вернул здоровый frontend 0.27.15. Для повторного выпуска права сборки исправлены. Перед переключением отдельно проверены запуск Node под UID 1000, импорт серверного модуля и ответ /healthz в итоговом образе.

Штатная проверка подтвердила здоровье нового frontend, сохранность 593 прежних ресурсов, состояния 11 остальных контейнеров и конфигураций Nginx. Test принял TLS 1.2 и отклонил TLS 1.3. После выпуска на общем диске VPS оставалось около 254 МиБ.
