# Навигация кабинета и выход: тестовая поставка 29.10.2026

На [тестовую площадку](https://play-and-say.ru/lastochka/) поставлен **frontend 0.15.2**. Пять ссылок кабинета имеют прямые углы, одинаковую высоту и центрированные подписи. «Выйти» находится в общей шапке только внутри административных разделов и безопасности; на публичных страницах для вошедшего администратора остаётся переход в кабинет. Отдельный выход ограниченной сессии сохранён. Сроки входа и минутные проверки состояния не менялись.

Backend **0.15.0**, PostgreSQL и схема **V18** остались без перезапуска. Production-поставка не выполнялась. Реализация и локальные ограничения описаны в [отчёте](../admin-navigation-and-session.md).

## Подготовка и поставка

- Повторная инвентаризация подтвердила frontend 0.15.1/backend 0.15.0/V18, здоровые сервисы, доступность соседних страниц и корректную конфигурацию Nginx. Общее хранилище спецификаций не использовалось.
- Проверенный frontend упакован локально в отдельный Linux/amd64 образ 0.15.2 с прежним runtime 0.15.1. Проверка зависимостей и совместимости V18/PASSWORD_LIFECYCLE_V1/RECURRING_GROUPS_V1/ENQUIRY_MULTICHANNEL_V1 прошла. Backend не пересобирался.
- До переключения создан приватный backup `/opt/lastochka/backups/pre-frontend-0.15.2-20261029T103637Z/`. Восстановление в отдельную временную БД выполнено; совпали 22 отпечатка таблиц. Временная восстановленная БД удалена. Копии конфигурации и env имеют закрытые права; секреты не выносились в отчёт.
- Пакет и manifest проверены на сервере. Из env изменён только `FRONTEND_IMAGE`; пересозданы только frontend и его прокси для обновления адреса upstream. Общие Nginx/TLS/ACME, соседние сервисы, backend/PostgreSQL и остальные значения env сохранены.
- Работающий SSR SHA256 `1a6dcb39f3fac89201c715ad138e606527e8d7e4df2c974c42eeb77fbe28ed15` совпал с локальной сборкой. Идентификатор образа `sha256:964fb52df8f0f4943adffee0efe17f7795e9bf0852fb1d47c9ffc87ff77ad8f6` совпал с пакетом. Readiness сообщает UP / 0.15.2.

## Приёмка на HTTPS

Выполнено **376 проверок**, включая доступность **332 прежних ресурсов** без подмены HTML. Четыре авторизованных контекста Chromium/WebKit × 375/1440 px, ru-RU/en-US прошли реальные переходы между всеми пятью разделами, определение текущего раздела, reload, проверку геометрии и возврат к публичному действию кабинета. Снимки безопасности на телефоне и компьютере просмотрены. Мобильное публичное меню ведёт к разделу расписания.

Открытая до поставки вкладка 0.15.1 сохранила переходы и ту же административную сессию после переключения. После reload отображается новый выход в шапке. Проверка выполнена на отдельном временном ADMIN, не на исходной сессии пользователя.

Проверены предупреждение о несохранённом вводе и отмена выхода с сохранением текста/сессии. Изменяющие команды и сохранение черновика в этой приёмке не отправлялись. Искусственный сетевой отказ выхода не выдаётся за успех; после снятия отказа настоящий серверный выход отзывает текущую сессию, закрывает административный API и обновляет вторую вкладку. Публичная форма заявки без JavaScript открывается с прежними полями и действием отправки; настоящая заявка на площадке не отправлялась.

## Сохранность и очистка

После приёмки адресно удалён один собственный временный ADMIN и его сессии, принадлежащие ему служебные записи и аккаунтный лимит. Бизнес-записи не создавались. Общий лимит по IP оставлен для штатного истечения. Локальные временные пароль и cookie-файл удалены.

Повторная проверка подтвердила **три исходных ADMIN и совпадение всех 22 отпечатков**, включая пароли, ключи, версии доступа, расписание, заявки, настройки уведомлений и подписки push. Контейнеры backend/PostgreSQL и соседей сохранили идентификаторы образов, контейнеров и время запуска. Файлы общих конфигураций, не относящиеся к frontend значения env и содержимое соседних страниц совпали с исходным снимком. Обновление не меняло generation и политику сессий.

## Откат

Подготовлен frontend-only откат на **0.15.1** с тем же backend **0.15.0/V18**:

```bash
python3 /opt/lastochka/releases/frontend-0.15.2/server-ops.py rollback
```

Проверены прежний образ, его совместимость и доступность старых ресурсов. Реальное переключение назад не выполнялось. Старый dump нельзя восстанавливать поверх актуальных данных; откат не требует восстановления БД или старого backend.
