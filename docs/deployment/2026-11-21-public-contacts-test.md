Свежая копия `/opt/lastochka/backups/test/pre-contacts-v33-20261121T183611Z-ab58a054/test-v32.dump` восстановлена в отдельном PostgreSQL без сети. Её SHA-256 — `79565c1df19421aae8945b9cc692e3d540327494ca42146e7295720fcb015caa`.

V33 обновила два поля и подняла ревизию контента с 3 до 4. Отпечатки остальных 29 таблиц совпали, V33 успешна в истории Flyway. Контейнеры backend и frontend тестовой зоны достигли состояния healthy. Идентификаторы, образы и время запуска остальных девяти контейнеров совпали. Контрольная сумма конфигурации Nginx совпала. TLS 1.2 принят, соединение с обязательным TLS 1.3 отклонено.

## Приёмка

- Публичный API вернул актуальные телефон и почту, ETag `"landing-4"`. Афиша вернула пять возрастных категорий и 14 интервалов.
- В Chromium и WebKit на HTTPS проверены компьютер 1440 px, мобильный экран 390 px и экран 320 px без JavaScript. Сверены обе ссылки `tel:`, подпись и `mailto:`, клавиатурный фокус и касание. Почта доступна целиком, высота ссылки 44 px, горизонтальной прокрутки нет. Открылась форма `/enquiry`, проверено назначение ссылки ВКонтакте. [Снимки](evidence/public-contacts-test-20261121/index.md).
- Все 528 сохранённых ресурсов прежних сборок доступны по HTTPS и совпадают по SHA-256. Адрес `/lastochka/` возвращает перенаправление 308 на главную.
- На локальной чистой базе и восстановленной копии проверены новые данные и ревизия. Проверены прежний документ без почты, чтение старым backend на V33, предупреждения и сохранение изменённых контактов. TypeScript, production-сборка, проверка языка и строгая проверка OpenSpec пройдены. Задачи выполнены 4/4.

Звонок и отправка письма не выполнялись. Мобильная проверка выполнена в эмуляции. Фактический откат на стенде и отправка заявки не проверялись.

## Возврат

Предыдущий frontend `0.25.1-enquiry-card-test-20261120` использует прежний интерфейс и получает новый телефон от backend. Предыдущий backend `0.25.0-permanent-week-test-20261119` локально прочитал обновлённый документ V33 при отключённом runtime Flyway. Конфигурация предыдущей пары сохранена в закрытом каталоге выпуска. Для возврата самих контактов потребуется адресная публикация с новой ревизией.
