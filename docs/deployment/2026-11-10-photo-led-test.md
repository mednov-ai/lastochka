# Выпуск сайта с фотографиями на test — 10 ноября 2026

По запросу пользователя на `https://test.lastochka-gym.ru/` выпущен frontend `0.20.1-photo-test-20261110`, образ `sha256:2659751cbc3ff328fee21f6b783e8e6078e59db8c8b7a07f5c4390627d57dd1e`. На странице снова размещены изображения из предоставленной презентации, а обе ссылки сообщества ведут на `https://vk.ru/lastochkagym`. Изменение `restore-photo-led-public-design` выполнено 14/14, но не архивировано.

## Подготовка и выпуск

- Typecheck, проверка языка и сборка frontend прошли; проверка меток подтвердила совместимость нового интерфейса с backend V24. Архив образа `frontend.tar` имеет SHA-256 `7ef116f82b31b1af1f1b647df73b7bc5bc31f39243dd4ca3260e2875f7fb7895`; после передачи сумма совпала.
- На одноразовом локальном стенде со старым root frontend 0.20.0 и новым 0.20.1 проверены обновление открытой вкладки и переход к заявке, а также шесть браузерных сценариев Chromium/WebKit, включая тестовый вход, WebAuthn и форму без JavaScript. Фикстура использовала отдельную временную БД.
- Выпущен только test frontend; сохранены прежний image и файлы ресурсов. Служебная конфигурация прежнего frontend сохранена в `/opt/lastochka/backups/test/pre-photo-20261110T185208Z-3b6a0ef320e2/root-release.env`. Внутренний IP frontend сохранился; test backend, PostgreSQL и прокси не перезапускались. Фактический откат не выполнялся; предыдущий frontend 0.20.0 совместим с текущим backend V24 по предварительной проверке.

## Проверки после выпуска

- Test `/` доступен по HTTPS, `/lastochka/` перенаправляет на корень. На desktop и mobile проверены изображения, правильный VK, переключение недели, форма для ребёнка и переход к форме для себя; на 390 px горизонтального переполнения нет. `hero.webp`, `mini-group-v2.webp`, `individual.webp`, `coach.webp` и логотип проверены по SHA-256 относительно локальных ресурсов.
- Все 64 файла предыдущей сборки доступны по HTTPS с прежними контрольными суммами. Реальная вкладка test, открытая до обновления на корневом адресе, после выпуска перешла к форме заявки; никаких заявок ею не отправлялось.
- Тестовый PostgreSQL, backend и frontend работают и здоровы, сохранённая конфигурация указывает на новый образ. Test и production принимают TLS 1.2 и отклоняют TLS 1.3; публичная страница production по-прежнему показывает заглушку. Production в ходе выпуска не менялся.
- Отдельная более старая фикстура с вкладкой на прежнем подпути `/lastochka/` дважды не открыла форму после переключения на корень и показала страницу ошибки. Это не сценарий текущей корневой версии test; прямое обновление старого адреса формы перенаправляется на `/enquiry` и возвращает 200. Уже открытой очень старой вкладке может понадобиться обновление страницы.

Реальная отправка заявки, существующая ADMIN-сессия, физические телефоны, скринридеры и фактический откат не проверялись. Условия бесплатного первого индивидуального занятия и применимость цен 6400/950 к группе остаются неуточнёнными. Изображения и дизайн прошли локальные проверки, описанные в [отчёте реализации](../photo-led-public-redesign.md).
