# Уведомления ВКонтакте на test

22 ноября 2026 года backend и frontend `0.26.0-vk-notifications-test-20261122` выпущены на [тестовом сайте](https://test.lastochka-gym.ru/). Схема PostgreSQL обновлена до V34. В разделе «Заявки → Уведомления о заявках» администратор подключает закрытую беседу ВКонтакте. Браузерный push настраивается отдельно, история доставки Telegram доступна в карточке заявки.

## База и окружение

Свежая резервная копия `/opt/lastochka/backups/test/pre-vk-v34-20261122T161622Z-f1413f75/test-v33.dump` восстановлена в отдельном PostgreSQL без сети. SHA-256 копии `eda04ed5238c5dfc609d1a77530e491b2846f36d8e55c2ee6d21fccfa81707f3`. На восстановленной копии проверены V34 и права роли приложения. После применения миграции на test совпали отпечатки 29 прежних таблиц и документ главной страницы. Flyway подтвердил V34. Ключ шифрования для test доступен процессу backend через монтирование только для чтения.

Новые backend и frontend достигли состояния healthy. Идентификаторы, образы и время старта остальных девяти контейнеров совпали. Совпала контрольная сумма конфигурации Nginx. На HTTPS TLS 1.2 принят, клиент с обязательным TLS 1.3 получил ответ `protocol_version`.

## Приёмка

- На HTTPS проверены главная, контакты и форма заявки. API афиши вернул пять категорий и 14 интервалов. Запрос без сессии к API настроек ВКонтакте получил 401.
- На сайте проверены формы ВКонтакте и браузерных уведомлений в Chromium (1440 × 900) и WebKit (эмуляция 375 × 812). Для кабинета использованы подставные авторизация и ответы API. Обе панели загружаются и восстанавливаются независимо. [Снимки](evidence/vk-notifications-test-20261122/index.md).
- Все 530 сохранённых ресурсов прежних сборок доступны по HTTPS и совпадают по SHA-256.
- Локально проверены миграция, роли, шифрование и замена ключа, независимое сохранение браузерных настроек, переход к карточке после входа и повтор отправки после перезапуска с прежним идентификатором VK. Внешний VK API заменён имитатором. Gradle check, сборка frontend и строгая валидация OpenSpec пройдены.

Для фактической приёмки остаются сообщение в тестовой беседе ВКонтакте и push при закрытой вкладке. На test ключ сообщества и ключи VAPID ещё не заданы, backend использует внутреннюю сеть, фоновые обработчики выключены. Реальный вход ADMIN, физические устройства и откат на стенде отдельно не проверены. [Инструкция владельцу и оператору](../vk-enquiry-notifications-operations.md).

## Возврат

Миграция V34 аддитивна. Резервная копия V33 предназначена для отдельного восстановления. Для отката приложения нужна проверенная V34-совместимая сборка с отключённым Telegram. Прежняя конфигурация пары backend и frontend сохранена в закрытом каталоге выпуска.
