# Компактная типовая неделя на test

26 ноября в реальном кабинете Chrome проверены 14 интервалов и пустое воскресенье. В версии 0.27.13 у кнопок «Изменить» во второй колонке обнаружилось смещение до 17,8 px в зависимости от длины подписи возраста. В выпущенной версии 0.27.14 координаты времени, возраста и действия совпадают между днями.

## Состав

- Ревизия реализации в `develop` — `c6791b2`, база после ребейза — `1280ca9`. Для сборки использованы сохранённые исходники frontend 0.27.12 с уже опубликованными интерфейсами ВКонтакте, реестра заявок и Альфа-Банка. Среди файлов приложения изменён только `frontend/app/ui/weekly-editor.css`.
- Образ linux/amd64 — `lastochka-frontend:0.27.14-aligned-week-test-20261126`, идентификатор `sha256:6324f9fbe7e0503757e5f3f711856fe2908a3e1de5237da04d27328f469f5444`. Тестовый сайт отдаёт `manifest-98056716.js`.
- Проверены здоровье frontend, контрольные суммы 588 прежних ресурсов, состояние 11 остальных контейнеров и конфигурации Nginx. Test принял TLS 1.2 и отклонил TLS 1.3. Версия backend — 0.27.11, схема V35.

## Приёмка

| Проверка | Результат |
| --- | --- |
| Видимость при 1440 × 900 | До уплотнения нижний край воскресного текста был на 1292 px. После исправления он на 804 px, верх подвала на 847 px. Все 14 интервалов видны при открытии. |
| Колонки в Chromium и WebKit | Измерены левые координаты времени, категории и кнопки для каждой позиции занятия по всем дням. Максимальный разброс на test — 0 px при ширине 1440, 375 и 320 px. |
| Сценарии на тестовых данных | Все 14 кнопок открывают нужное время. Проверены Tab, Escape, возврат фокуса, добавление интервала, справочник, роль с правом просмотра, четвёртый интервал и длинная архивная категория. |
| Размер текста и управление | На мобильных размерах проверены текст 200%, прокрутка к воскресенью и область касания от 44 px. Телефонные размеры эмулировались. |
| Автоматические проверки | Сборка, проверка типов, проверка русского текста и шесть сценариев набора `playwright.permanent-current.config.ts` прошли. В набор включена регрессия на выравнивание колонок между днями. |

Браузерные измерения выполнены на опубликованном интерфейсе с подставным API. В открытой вкладке пользователя после обновления отдельно проверено отображение реального тестового расписания. Баннеры состояния и число интервалов могут увеличить высоту страницы.
