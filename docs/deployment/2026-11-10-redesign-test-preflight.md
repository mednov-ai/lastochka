## Проверки

- Тесты backend-модулей заявок и расписания, проверка архитектуры, типы, проверка языка и production-сборка frontend прошли.
- Кандидатные образы запущены только на одноразовой локальной БД. Два последовательных прогона проверили сохранение старой открытой вкладки, корневые и старые адреса, вход, параметры ключа и форму без JavaScript; каждый включал 6 сценариев Chromium/WebKit. Первый предварительный прогон завершился тайм-аутом старой вкладки; причина не установлена, два последующих прогона прошли.
- Тестовый сайт доступен, HTTPS подтверждён с TLS 1.2; TLS 1.3 отклонён. Ревизия опубликованного контента test — 2. История миграций недоступна роли чтения; для проверки схемы был ошибочно использован операторский доступ к тестовой БД. Он показал V21, данные не изменялись. Далее использовать разрешённый механизм тестовой зоны.
- Публичный API test показывает исходные значения для семи участков текста, на которые рассчитана V24 (заголовок и описание сайта, заголовок, текст и аудитория первого экрана, вопросы о возрасте и заявке). На момент чтения известных конфликтов этих значений нет; перед миграцией нужно учитывать возможные последующие изменения содержимого.
- Локальная виртуальная машина Docker до работы завершилась с ошибкой. После восстановления Docker автоматически запустил имевшие такую настройку локальные контейнеры; логи двух местных backend показали отсутствие новых миграций при старте. Никакие тома или образы не удалялись.
- Ресурсы VPS на момент проверки: около 457 MiB доступной памяти, 11 GiB свободного диска. Это не нагрузочное испытание. До создания резервной копии и отдельного стенда повторно оценить запас памяти; восстановление желательно выполнять вне VPS.
