# Векторный логотип и увеличенная шапка

24 октября 2026 года локально реализовано `vectorize-logo-and-enlarge-header`.
Этот локальный этап сервер не менял. Позже 24.10.2026 по отдельному поручению
поставлен frontend0.9.1 и изменение архивировано; backend0.9.0/V12 сохранены.
[Поставка и приёмка](deployment/2026-10-24-vector-logo-header.md).

## Результат

`frontend/public/images/logo.svg` содержит настоящие векторные контуры силуэта,
ласточки, декоративных элементов, названия и подписи. Фон прозрачный, лишние
поля убраны; raster image, текстовых элементов, шрифтов, скриптов и внешних
ссылок нет. Исходные JPEG сохранены. Подробности трассировки и ручной очистки —
в README ресурсов. SVG визуально сверен с оригиналом, включая мелкую подпись,
при увеличении 200% и плотности 1×/2×. Это векторная производная прежнего знака.

Общая шапка использует SVG через BASE_URL с размерами 600×195, соответствующими
viewBox. Убран mix-blend-mode. Навигация увеличена до 15 px; общий контейнер
допускает перенос элементов. На телефоне действия располагаются второй строкой.
Переходы, русские доступные названия и общий сценарий входа сохранены.

| Ширина окна | Шапка до → после | Элемент логотипа до → после |
| --- | --- | --- |
| 375 px | 109,375 → 179,375 px | 145,5×73,375 → 195×63,375 px |
| 1440 px | 163,391 → 176 px | 205×103,391 → 280×91 px |

Важна видимая композиция: старый JPEG включает большие белые поля. В новом
ресурсе фигуры и надписи занимают почти всю площадь, поэтому уменьшение высоты
самого img не означает уменьшения рисунка. Снимки до/после подтверждают увеличение.
Фактическая прежняя высота шапки превышала min-height 120/92 px из-за JPEG;
новые минимумы выбраны 176/128 px с учётом этого измерения и мобильного переноса.

## Проверки

- 16/16 сценариев `playwright.header.config.ts`: Chromium/WebKit × en-US/ru-RU
  × 375/1440 px, гость/ADMIN, вход с ошибкой и возврат фокуса, заявка, маршруты
  расписания/заявки/кабинета, ссылка на главную, reduced-motion, no-JS, touch,
  DPR2 и снимки увеличенных контуров.
- В каждом сценарии ADMIN проверены 320/375/390/599/600/601/679/680/681/768/
  999/1000/1001/1024/1440/1920 px; дополнительно измерены те же ширины у гостя
  и ADMIN. Пересечений с логотипом и выхода действий за экран нет.
- 11/11 существующих сценариев `landing.spec.ts`, `landing-visual.spec.ts`,
  `format-composition.spec.ts` на production-сборке: композиция, портрет,
  прямой/обратный scroll, hover/focus, touch и fallback.
- CPU ×4, wheel/video/trace: P95 16,7 ms на 375/1440 px; длинных задач нет.
  Доля кадров >50 ms: 0% на 375 px, 0,565% (1/177) на 1440 px,
  в пределах существующего критерия регрессии.
- `npm run typecheck`, `npm run build` и встроенный `check:ui-language` прошли;
  проверено 1019 пользовательских фрагментов, нарушений 0. Сохраняется прежнее
  предупреждение сборщика о совместном статическом/динамическом импорте AuthForm.
- Отдельная копия исходников без `info/`, без готовых build и с установленными
  зависимостями успешно прошла typecheck и production build. SVG присутствует
  в готовом frontend и отдаётся как image/svg+xml с тем же содержимым.
- `openspec validate vectorize-logo-and-enlarge-header --strict` пройден.

Повторяемый запуск проверки шапки из `frontend/`:

```sh
TEST_DATABASE_CONTAINER=lastochka-concept-postgres npx playwright test --config playwright.header.config.ts
```

Требуются изолированные acceptance backend на 8097, frontend SSR на 5180 и
локальный proxy на localhost:5179. Перед повторными входами тест адресно очищает
только два limiter bucket fixture-admin/127.0.0.1 в отдельной
`lastochka-concept-postgres`; запуск против иной БД/адреса запрещён проверкой.
Первый полный прогон выявил накопленные попытки тестового входа; после этой
подготовки стенда итоговые 16 сценариев прошли полностью. Для WebKit используется
Alt+Tab, учитывающий стандартный режим перехода по ссылкам на macOS.

Локальные доказательства исключены из Git: `artifacts/vector-logo/` содержит
before/after JSON и снимки, снимки DPR2/200%, `header-checks.log`, `regression.log`,
`clean-build.log` и `regression/landing-refinement/` с wheel-видео и trace.
