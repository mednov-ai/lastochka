# Новое еженедельное занятие

29.10.2026 `simplify-new-recurring-session` поставлено на тестовый сервер в backend/frontend 0.16.0 и архивировано; production не обновлялся. [Отчёт поставки и архивирования](deployment/2026-10-29-inline-weekly-session.md). Ниже сохранены результаты локальной реализации на момент до поставки.

При подготовке поставки исправлены прежние замечания форматирования, и полный `format:check` прошёл.

При создании нового группового занятия «Еженедельно · выбрать дни» раскрывает дни недели и последнюю дату в той же форме. Изначально выбран день даты начала и период в четыре недели; название, время, длительность, вместимость и возраст сохраняются при переключении и возврате с проверки. Существующая группа выбирается явно. Если она не выбрана, отдельное название группы вводить не нужно: при сохранении новая группа получает название, вместимость и возраст занятия. Совпадающая по имени группа не выбирается автоматически.

Проверка для ещё не созданной группы не создаёт данных. Новый серверный метод сохранения атомарно создаёт группу и черновик серии одной идемпотентной командой; ошибка не оставляет отдельную группу. После проверки для публикации черновик и план повторно проверяются по серверным версиям и занятости. Сохраняются отдельное подтверждение, полный список дат, конфликты, безопасный повтор и существующий редактор сохранённых групп/серий. После публикации действие «Изменить расписание» открывает существующий редактор с причинами отмены и сохранением исключений.

Крестик центрирован; у содержимого есть место под контур фокуса. Поля возраста на узком экране располагаются в одну колонку; в очень низком окне активное поле прокручивается в видимую область. Устранена лишняя перерисовка формы при вводе без ошибок — именно при ней в локальных проверках ранее терялся первый символ при быстром вводе.

## Проверка

- Сервер: 15 интеграционных тестов серий, включая предпросмотр без записей, откат создания группы при неверном правиле, повтор с тем же ключом и полную публикацию. Проверка архитектуры и сборка backend прошли.
- 28 целевых браузерных сценариев в Chromium/WebKit при 375/1440 px и ru-RU/en-US: сохранение введённого названия, выбор группы и дней, 12 дат, переход к редактированию опубликованной серии, конфликты, повтор после потери ответа, защита выхода и быстрый ввод/вставка. После последнего сокращения подписи группы повторно прошли 8 сценариев полного пути и геометрии.
- Геометрия 10 полей проверена в шести условиях: 320, 375, 768 и 1440 px, 375 px при 200% текста, а также 320×400 px. Проверены четыре стороны контура и центр крестика; Safari проверен движком WebKit, не на физическом устройстве.
- 24 регрессионных сценария компактного календаря прошли на той же локальной изолированной базе. Они покрывают отдельные занятия, историю, изменение дней серии и восстановление после потери ответа. После последних визуальных правок повторно прошли 16 сценариев календаря.
- `npm run typecheck`, `npm run build`, проверка пользовательского языка и 4 теста языковой проверки прошли. Затронутые файлы Prettier проверены; общий `format:check` по-прежнему указывает на прежний посторонний `frontend/tests/admin-gesture.spec.ts`.
- `openspec validate --all --strict`: 20 passed, 0 failed. Изменение не архивировано.

Проверки выполнены на собственных локальных PostgreSQL/backend/SSR и тестовой учётной записи; данные тестового сервера не использовались. Для повторения браузерных проверок нужен выделенный контейнер `lastochka-new-weekly-postgres`, база `lastochka_weekly_fixture` и локальный backend/frontend по `http://localhost:18111/lastochka`; конфигурация — `frontend/playwright.new-recurring.config.ts`. Тесты очищают `auth_limits` только в этом отдельном контейнере.

Изменение затрагивает backend и frontend, но не добавляет миграции. Для поставки сначала использовался совместимый backend с новыми операциями, затем frontend; новый frontend с прежним backend 0.15.0 не поддерживает создание серии с новой группой. Авторизованная приёмка на тестовой площадке описана в отчёте поставки; физические устройства и удалённый CI отдельно не проверялись.
