# Локальная проверка интеграций — 13.11.2026

Все данные, банковские ответы и пользователи в проверках синтетические. Тестовый и production-серверы, их базы, реальные реквизиты и банк во время этой работы не использовались. Заданные пользователем незакоммиченные изменения сохранены в исходной рабочей папке; реализация находится в отдельном worktree.

- `python3 scripts/test-alfa-environment-migration.py`: PostgreSQL без сети, проверка ограничений среды, неизменяемых идентификаторов, отдельных архивов, результата отмены и двух конкурентных вызовов реального SQL создания одной попытки. Проверка фикстуры не подтверждает реальный банковский платёж.
- `python3 scripts/test-alfa-legacy-migration.py`: восстановление синтетической V27-копии в отдельной внутренней сети Docker; отдельный вход упакованного JAR запускается непривилегированной ролью; неверные зона/идентификатор, неподходящий контекст, испорченная ссылка и противоречащее test переопределение флага отклоняются, корректные TEST-шифротексты, запись администратора и запись сессии сохраняются. Это не восстановление реальной базы или её ключей.
- На временном изолированном backend выполнялись прямые HTTP-запросы с синтетическими ADMIN и STAFF: запрет боевой конфигурации на test, подмена заголовка среды, CSRF, права, блокировка старого контракта при наличии синтетической боевой попытки и запрет её банковских команд. Внутренняя сеть не имела доступа к банку.
- Изолированный Gradle-контейнер без сети: 58 избранных unit-тестов модуля оплат, включая ключи/AAD, ротацию, кандидатов и гонки, разделение запросов, потерянный ответ, сверку валюты, TLS, callback и права; компиляция интеграционных тестов backend, `bootJar`, архитектурный контроль и тесты его правил. Реальные sandbox-тесты исключены.
- `npm run build`, `npm run typecheck`, `check:ui-language`: пройдены. Playwright с подставными API: 50 проверок разделов безопасности/интеграций и 32 проверки оплат в Chromium и WebKit. Обзор, размеры, скриншоты и ограничения: [проверка интерфейса](alfa-integrations-ui-review.md).
- `openspec validate integrate-alfa-test-payments --strict`, `openspec validate separate-alfa-gateway-integrations --strict`, `python3 scripts/check-concept-release.py --self-test`, `python3 scripts/test-isolated-compose.py`: пройдены.

Физические устройства и скринридеры, действующие банковские API, реальное состояние администратора `admin1`, реальное восстановление, серверный TLS и поставка на test в этом прогоне не проверялись. Production-выпуск и реальные платежи требуют отдельного разрешения и закрытия банковских и организационных предпосылок. До завершения проверки реализации боевой выпуск программно заблокирован.
