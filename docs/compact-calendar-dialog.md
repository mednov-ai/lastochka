# Компактный редактор календаря

27.10.2026 реализовано `compact-calendar-dialog-and-simplify-editing`.

Причиной ощущения «крестик не работает» было встроенное предупреждение, которое
раздвигало форму вместо закрытия. Неизменённая форма теперь закрывается сразу
крестиком/Escape. При реальном вводе появляется отдельное короткое подтверждение
«Остаться»/«Выйти»; Escape закрывает только верхнее подтверждение. Сохранённый
серверный черновик не удаляется. Закрытие во время записи не обещает отмену операции.

Редакторы занятия и серии получили рамку до1000×680px с отдельными заголовком,
содержимым и действиями. На1280×800/1440×900/1522×1230 основной шаг помещается
без прокрутки. При200% текста, на телефоне и коротком экране разрешена внутренняя
вертикальная прокрутка; при экранной клавиатуре действия входят в ту же область
прокрутки. Лендинг и прочие панели не получают новые размеры.

Группы, создание группы, параметры серии, проверка и история разделены. Возраст
сворачивается в дополнительные параметры без потери значений. Черновик сохраняется
прямо из параметров; публикация требует отдельного актуального плана. Все200 дат
достижимы страницами по10, конфликт последней даты блокирует весь план. Причина
отмены появляется только при фактических отменах. Просмотр карточки не отправляет заявку.

Новое занятие/серия получает60 минут. Кнопки и ArrowUp/Down меняют длительность
на30 минут, ручной ввод сохраняет точные положительные значения50/53. Выделенные45
минут и точное исходное время не округляются; сетка сохраняет шаг15 минут.
Окончание показывается по МСК, включая следующую дату.

После10 секунд без определённого результата запись видна в общей области статуса.
Контекст повтора принадлежит текущей вкладке и ADMIN, переживает закрытие/reload,
содержит исходные команду и ключ, не выполняется автоматически. Пароли и контакты
в него не включаются. Повтор использует тот же ключ; после24 часов предлагается
ручная сверка вместо новой записи под видом повтора. Выход/смена ADMIN очищает контекст.
Неверный JSON даже приHTTP200 не выдаётся за успешную запись. Поздний ответ не открывает окно.

## Проверка

- 80/80 сценариев Chromium/WebKit ×ru-RU/en-US ×375/1440, без пропусков и flaky.
- 104/104 регрессионных сценария телефона, паролей и фокуса.
- 376 измерений подписи/фокуса: минимальный зазор5px, контраст6,43:1.
- Дополнительно:20-секундный ответ, повтор тем же ключом при ещё открытом запросе,
  отсутствие дубля/позднего открытия, неверный JSON, coarse pointer, поля16px,
  цели44px, reduced-motion,200% и короткий экран в обоих движках.
- Полная цепочка200 дат, конфликт последней даты, версия/исключение, потерянный
  ответ публикации, история одиночного занятия, восстановление черновика и отмена.
- Проверки языка, типов, production build, форматирования и strict OpenSpec прошли.
  Backend/API/зависимости и схемаV15 не менялись.

Доказательства: `artifacts/compact-calendar/results.json`, `regression-summary.json`,
`focus-summary.json`, `extra/results.json`, `screenshots/`.
Исходное окно:720×900px, содержимое1555px; новый desktop основной шаг без прокрутки.
