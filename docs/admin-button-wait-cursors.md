# Курсор и ожидание в кабинете

12.11.2026 локально проверен frontend на изолированных ответах API. В Chromium у «Проверить реквизиты» и «Отключить подключение» при пустых настройках вычисленный курсор был `wait`, хотя обе кнопки отключены без запроса. После исправления он `default`; нативное отключение сохранено. Как системный указатель выглядел у пользователя, а также его браузер и устройство неизвестны.

В коде те же стили применяются к «Подтвердить публикацию», «Создать платёжную ссылку» в форме черновика и другим отключённым `.button`. Публикация зависит от черновика, несохранённого ввода и выполняемой команды; создание ссылки в форме всегда отключено, а тестовая ссылка создаётся из списка активных оплат. Границы пагинации, права и отключённые `fieldset` также могут отключать действия без запроса. На публичном сайте общий стиль используют формы; мобильное меню имеет отдельный курсор до готовности управления.

Локальная правка заменяет ошибочный курсор, сохраняет блокировку и добавляет текстовые статусы настоящих операций. Рабочие базы и серверы не использовались.

## Проверки и ограничения

- Playwright: 13 сценариев Chromium для кнопок, ошибок, пагинации, прав, редактирования и оплат; ещё 8 сочетаний Chromium/WebKit, ru-RU/en-US и 375/1440 px для состояний и задержанного ответа. Синтетическая ошибка сохраняет ввод, кнопка снова доступна, повторная команда не отправлена.
- `playwright-cli`: вычисленный курсор до/после, клавиатура и задержанный ответ, форма черновика; синтетическая публичная заявка на 375/1440 px и ru-RU/en-US, мобильное меню и имитация касаний. Подтверждение публикации при несохранённых правках и его курсор проверены отдельным Chromium-тестом.
- `npm run typecheck`, `npm run build`, проверка русского текста, форматирование затронутых файлов, `git diff --check` и strict OpenSpec прошли. Обзор затронутых состояний по свежим `web-design-guidelines`: использованы нативное отключение, статусы и сообщения ошибок; новых замечаний по изменённым состояниям не выявлено.
- Использованы локальные синтетические ответы без настоящих операций с банком и рабочими данными. Физические устройства, скринридеры, Firefox и фактический курсор в браузере пользователя не проверены. Выпуск test и production не выполнялся.
