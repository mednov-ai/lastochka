# Бирюзовая гамма и удаление подписи дизайн-концепции

24 октября 2026 года реализовано `refresh-turquoise-brand-and-remove-design-caption`.
Результат поставлен как frontend **0.9.3**; backend **0.9.0** и PostgreSQL **V12**
сохранены. [Отчёт поставки](deployment/2026-10-24-turquoise-brand.md).

## Изменения

- Удалены figcaption «Иллюстрация из дизайн-концепции» под изображением тренера
  и его отдельные стили/отступ. Полная композиция, сведения и CTA тренера сохранены.
  Только точный исходный alt «Иллюстрация тренера; изображение из дизайн-концепции»
  упрощён до «Иллюстрация тренера»; иной опубликованный alt не перезаписывается.
  Подпись hero «Иллюстрация занятия» сохранена. Сведения о происхождении есть в README.
- Новый `logo-turquoise.svg`: цветная группа#168f94, силуэт#234b50;
  золотистые детали, тёмная подпись, все path/transform/viewBox и прозрачность
  исходного SVG сохранены. Старые SVG/JPEG доступны, info не менялся.
- Общие CSS-роли согласованы для лендинга, шапки/подвала, ссылок/кнопок,
  фона/декора, гостевых форм, календаря и административных панелей.
  Основной акцент#167f82, hover/контрастный текст#10666a, фон#f7fbfa,
  подложки#e8f5f3/#ddf1ef, основной текст#203637, второстепенный#526b6b.
  Значимые границы полей#648b8b; бледные декоративные границы отделены от них.
- Общий фокус полей бирюзовый; текст/фон отключённых кнопок сохраняет читаемость.
  Семантические цвета успеха, ожидания, отказа и ошибок сохранены отдельно.
  Фильтры для изображений не добавлялись. SVG имеет новый URL для отделения кеша.
