# Публичные документы сайта

12.11.2026 изменение выпущено на test и архивировано; актуальные проверки поставки — в [отчёте](deployment/2026-11-12-public-legal-documents-test.md). Следующий раздел описывает локальную реализацию до выпуска.

Источники — два DOCX из письма от 10.11.2026, сохранённые в `openspec/changes/archive/2026-11-12-add-public-legal-documents/sources/`. Тексты перенесены из `word/document.xml` с сохранением последовательности абзацев, переносов, маркированных пунктов и реквизитов; машинная сверка каждого непустого абзаца и типа пункта с созданным JSON прошла без расхождений. В политике 80 блоков, в соглашении 68; из них 44 и 26 — пункты списков соответственно. При переносе ничего не исправлялось по смыслу.

Контрольные суммы SHA-256: политика `05cc3b9a9eaa725dd01f29d0ecfe18236e060047eb2b90d41265364d16aee91e`, соглашение `712278b3ca26c2cacd0588fab0ab7462291053b47b8fbcf73166ec41be0e5d3f`.

Юридическая достаточность текста и соответствие описанной в нём обработки фактической работе не проверены; документы утверждают, что согласие возникает при использовании сайта. Ответственному за документы необходимо проверить эти формулировки. Публикация страниц сама по себе не реализует и не подтверждает получение согласия.

## Локальная реализация и проверка

Созданы страницы `/legal/privacy` и `/legal/terms`, ссылки в общем подвале и структурированный контент frontend. В Chromium с синтетическим backend через `playwright-cli` проверены оба документа и ссылки на главной и в форме заявки в восьми сочетаниях: корень и `/lastochka/`, 1440×900 и 375×812, с JavaScript и без него. Прямые адреса, обновление, возврат на главную, наличие прежних ссылок, видимый фокус, отсутствие горизонтального переполнения и отсутствие POST при переходе из заполненной формы прошли. Все 148 отрисованных блоков сверены с перенесённым содержимым. Дополнительные два сохранённых Playwright-теста прошли в каждой из двух конфигураций.

По `web-design-guidelines` проверены затронутые ссылки и страницы: семантические ссылки и заголовки, видимый фокус, перенос текста, отзывчивость и состояние наведения. Расчётные соотношения контраста основного текста — 12,25:1 на фоне страницы и 11,43:1 на фоне подвала, ссылки возврата — 6,43:1. `npm run typecheck`, `npm run build` с языковой проверкой (2851 фрагмент, нарушений нет), `git diff --check` и строгая проверка OpenSpec прошли. Сборка выдала существующее предупреждение о смешанном импорте `auth-form.tsx`.

Проверки выполнены с подставными ответами backend; реальная авторизованная сессия, физические устройства, скринридеры, другие браузерные движки, CI и фактический откат не проверялись. Значение введённой формы после возврата браузером отдельно не гарантируется. Test и production не обновлялись.

## Последующая поставка и откат

Изменение требует только frontend, миграций БД нет. Перед возможной поставкой на test необходимо собрать и проверить версионированный образ для корневого адреса, сохранить доступ к старым ресурсам для открытых вкладок, проверить обе страницы и существующие переходы; применять действующий проектный порядок поставки. Для production нужна новая отдельная отмашка; действующий gate и TLS 1.2 сохраняются. Откат — предыдущий совместимый frontend с сохранением старых статических ресурсов; новые документы тогда станут недоступны. Фактическая поставка и откат не выполнялись.
