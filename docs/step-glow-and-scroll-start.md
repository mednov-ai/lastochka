# Заметное загорание номеров подхода

24 октября 2026 года реализовано `emphasize-step-glow-and-delay-scroll-start`.
Поставка frontend **0.9.4** описана в [серверном отчёте](deployment/2026-10-24-step-glow.md).

## Поведение

Подпись «Иллюстрация занятия» удалена из главного экрана вместе со стилем;
изображение, alt и поэтическая карточка «Маленькие шаги. Большая уверенность.» сохранены.
Номера 01–02–03 блока «Наш подход» получили зарезервированный контейнер64 px,
шар60 px, постоянный контрастный центр с номером18 px, бирюзовое заполнение,
мягкий световой ободок и рост примерно на6,67%. Текст не двигается.
Номера другого блока «Первое посещение» сохраняют прежнее оформление.

Каждый шар начинает подсветку после достижения его центром линии85% высоты
окна от верха, то есть после прохождения нижних15%. На горизонтальном ряду
начала дополнительно разнесены на8% высоты окна; длина перехода14%.
На вертикальном списке собственная геометрия каждого номера определяет старт.
При коротком окне интервалы сокращаются, чтобы завершение оставалось ниже шапки.
Прогресс линии равен среднему прогрессу номеров. Положение считается по
неподвижным контейнерам, поэтому масштабирование не меняет точки старта.

Единый rAF обновляет CSS-переменные, React state на кадр нет. Геометрия
кешируется и пересчитывается после resize/visualViewport resize, pageshow,
загрузки медиа/шрифтов и изменения контента. Обратная прокрутка возвращает
прежние фазы, остановка не запускает таймер. Без JS и при reduced-motion
видно завершённое спокойное состояние. Другие пресеты не сдвинуты.

## Проверка

- **16/16** новых сценариев: Chromium/WebKit ×en-US/ru-RU ×375/1440.
  Каждый номер проверен до порога, на0/25/50/75/100%, при возврате и остановке.
  Дополнительно320×568,768×600,375×600,200% текста, изменение заголовка,
  восстановление позиции, no-JS/reduced-motion и touch-переход к заявке.
- **48/48** проверок общей темы/шапки/форм прошли.
- **11/11** различных регрессионных сценариев лендинга прошли:9 в основном
  прогоне, исправленный сценарий линии и отдельно включённый production budget.
  Изменены прежние ожидания общего прогресса подхода; герой/форматы проверяются
  по прежним формулам, индивидуальные фазы подхода — отдельным новым тестом.
- **120** сочетаний фаз номеров: минимальный контраст текста6,708:1,
  границы относительно подложки6,001:1. Постоянный центральный диск исключает
  нечитаемые промежуточные сочетания белого текста со светлой заливкой.
- Видеозапись прямого/обратного wheel-scroll и trace при CPU×4,
  Chromium156.0.8078.4,375×900/1440×900: p95 **16,8/16,7 ms**, доля интервалов
  >50 ms **0**, long tasks **0**. По6 layout events за проход, максимум0,853/0,722 ms,
  layout на каждом кадре отсутствует. Отдельно записана сенсорная прокрутка.
- Typecheck/build, русский UI и форматирование затронутых файлов проходят.
  Общий format:check отмечает прежний незатронутый tests/admin-gesture.spec.ts;
  он не включён в эту правку. Чистая сборка без info
  выполнена на bundled Node24.19.0 с существующими зависимостями; client-файлы
  побайтно совпали с принятой сборкой, единственное различие SSR — комментарий
  пути к symlink node_modules. Принятый runtime-образ использует Node24.22.1.

В WebKit автоматическое reload на данном стенде возвращает scrollY к0;
проверка подтверждает корректную фазу после восстановления сохранённой позиции.
Это не повод запускать самостоятельную сцену от нуля. Первый запуск нового
теста ожидал восстановление позиции самим браузером; ожидание уточнено.
При параллельных тестах одна общая папка trace вызвала конфликт артефактов;
последующие прогоны использовали раздельные каталоги. Код приложения ради
этих исправлений проверочного инструмента не менялся.

Доказательства исключены из Git: `artifacts/step-glow/` — исходные/финальные кадры,
фазы, контраст, логи, wheel/touch video, trace и чистая сборка.
Это проверка описанного стенда; реальные телефоны отдельно не проверялись.
