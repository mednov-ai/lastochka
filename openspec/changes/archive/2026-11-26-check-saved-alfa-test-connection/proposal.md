## Why

В тестовой вкладке Альфа-Банка видны статус сохранённых реквизитов и дата последнего изменения настроек. Администратор не может узнать, принимает ли банк сохранённые реквизиты сейчас, без повторного ввода пары и подготовки её замены.

## What Changes

- Добавить действие «Проверить подключение» для ранее проверенной и сохранённой пары. По нажатию сервер обращается к тестовому банку и сообщает результат именно этой попытки.
- Если отдельно сохранена новая пара, показывать «Проверить новые реквизиты». Обе кнопки явно указывают, к какой паре относятся. При первом подключении форма предлагает сохранить реквизиты.
- Для диагностики использовать чтение статуса контрольного тестового заказа. Сохранённая конфигурация, выбор шлюза, платежи и введённый черновик формы сохраняются при любом результате.

## Impact

Изменение затрагивает серверный модуль платежей, описание OpenAPI, типы клиента, форму `AlfaSettings` и проверки этих компонентов. Банк уже поддерживается существующим клиентом. Миграции данных для проверки по запросу не требуются.
