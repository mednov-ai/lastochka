## Context

Корневой шаблон включает React Router ScrollRestoration. При запуске эффекта шапки useHeaderOffset также вызывает scrollIntoView для текущего якоря. SectionLink обрабатывает явный выбор раздела, включая повторное нажатие. Замер WebKit в proposal.md подтверждает итоговое смещение, но сам по себе не устанавливает порядок этих вызовов.

## Goals / Non-Goals

Изменение охватывает восстановление прокрутки публичной главной и показ ссылок общего подвала на телефоне. Сохранение видимости клавиатурного фокуса и измерение закреплённых панелей продолжают работать независимо от якорной навигации.

## Decisions

- На исходной сборке проследить координаты содержимого и вызовы прокрутки до и после гидратации. Для обновления использовать позицию текущей записи истории, включая нулевую. Устранить повторное выравнивание по якорю только при восстановлении этой записи.
- Для прямого открытия ссылки без сохранённой позиции оставить переход к разделу. Для явного выбора раздела после обновления обрабатывать само действие пользователя. Тип загрузки документа сохраняется при клиентских переходах и сам по себе недостаточен для их различения.
- Хранение общей координаты по URL смешало бы разные посещения страницы. Сначала использовать уже подключённое восстановление роутера и проверить его взаимодействие с браузером.
- Удалить мобильный переключатель из общей оболочки и CSS-правила, зависящие от его открытого состояния. Использовать существующую навигацию с доступным именем «Ссылки сайта». На ширине до 700 CSS px ссылки располагаются в обычном потоке, на большей ширине действует существующая настольная раскладка.

## Risks / Trade-offs

- Изменение высоты шапки может сдвинуть текст при прежнем scrollY. При проверке измерять положение одного и того же видимого элемента относительно окна до обновления и после стабилизации шрифтов и шапки.
- Однократная проверка в конце загрузки может пропустить видимый скачок с последующим возвратом. Проверить последовательность кадров после первого отображения восстановленного содержимого.
