## 1. Список и карточка

- [x] 1.1 Сверить локальный вариант списка с требованиями. Проверить две записи одного человека, открытие конкретной строки, пагинацию и возврат клавиатурного фокуса на прежнюю страницу списка.
- [x] 1.2 Довести карточку контакта и времени. На примере заявки №7 проверить видимый номер, адрес ссылки звонка, московское время, однократный вывод возраста и указание о согласовании даты.
- [x] 1.3 Проверить на изолированных примерах общую заявку, конкретную дату, взрослого, ребёнка, неизвестный формат снимка, переход через полночь и отсутствующие контакты установленного формата. Сверить показанные данные с исходными значениями.

## 2. Доставка и оплата

- [x] 2.1 Проверить оба канала, отдельный сетевой отказ, задержку при смене карточек и штатный повтор. Убедиться, что обращение читается и сбой заметен в свёрнутом состоянии.
- [x] 2.2 Проверить с правами ADMIN и STAFF видимость действий, контактные поля открытого черновика и отсутствие сохранения при закрытии. Проверить отказ при отсутствии доступа к заявкам.
