## Решение

В форме нового группового занятия повторение раскрывает дни и последнюю дату без замены диалога. Выбранная дата определяет первоначальный день, диапазон ограничен. Не выбранная существующая группа означает создание новой по параметрам занятия; совпадение имён не выбирает существующую группу. Обычное занятие и правки существующих серий сохраняют прежние маршруты.

Новые аддитивные серверные операции: проверка правила для ещё не созданной группы без записи и атомарное идемпотентное создание группы вместе с черновиком серии. Публикация использует существующий механизм версий, актуального плана и атомарной проверки. При изменении параметров после проверки план устаревает, перед публикацией сохранённый черновик проверяется повторно. Неопределённые команды продолжают использовать существующее восстановление по ключу и владельцу вкладки.

Новый сценарий заменяет прежний сценарий пустого списка групп в активной дельте compact-calendar-dialog-and-simplify-editing; отдельное управление уже созданными группами остаётся.
