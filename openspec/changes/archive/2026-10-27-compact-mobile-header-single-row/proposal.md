## Why

На присланном снимке с iPhone шапка занимает две строки: логотип и «Меню» расположены выше «Записаться». В frontend 0.9.8 это разрешено до 430 CSS px, но пользователь ожидает одну строку на iPhone 11 и более новых телефонах и согласовал удаление видимого слова «Меню».

## What Changes

- На мобильных ширинах 375–1000 CSS px при обычном размере текста закрытая шапка размещает логотип, основное действие и переключатель меню в одну строку высотой не более 104 CSS px без верхней безопасной области, с JavaScript и без него.
- Переключатель на всех мобильных ширинах показывает только иконку: ☰ в закрытом состоянии и крестик в открытом. Русское доступное имя «Меню» и состояние раскрытия сохраняются.
- «Записаться» и «Кабинет» остаются видимыми текстовыми действиями; SVG сохраняет композицию, пропорции и ширину не менее 150 CSS px в однострочном варианте. Области нажатия — не менее 44×44 CSS px.
- На 320–374 CSS px и при увеличении текста до 200% разрешён перенос ради доступности; пункты раскрытого меню располагаются под строкой управления.
- Проверки учитывают границы 374/375 и 430/431, гостя/ADMIN, no-JS и WebKit. Трактовка «iPhone 11 и выше» задаётся шириной CSS viewport от 375 px, без определения модели или User-Agent.

## Capabilities

### New Capabilities

Новых возможностей нет.

### Modified Capabilities

- `public-landing`: однострочная мобильная шапка от 375 CSS px и управление меню иконкой с сохранением доступности и существующей навигации. Уточняются основное требование адаптивной шапки и действующие дельты `pin-mobile-header-and-relocate-admin-entry` / `add-mobile-header-section-menu`.

## Impact

Ожидаемые участки реализации: `frontend/app/styles.css`, `frontend/app/ui/mobile-navigation.tsx`, при необходимости разметка шапки в `frontend/app/root.tsx`; проверки `mobile-menu.spec.ts` и `logo-header.spec.ts`. Тексты доступности берутся из общего русского каталога. Backend, API, схема БД и данные не затрагиваются.

Порядок последующей синхронизации пересекающихся требований: `pin-mobile-header-and-relocate-admin-entry` → `add-mobile-header-section-menu` → это изменение. Этот proposal не выполняет реализацию, деплой или архивирование; шесть ранее поставленных изменений сохраняют свой статус.
