## ADDED Requirements

### Requirement: Компактная пагинация пользователей
Навигация пользователей SHALL иметь визуально компактные кнопки «Назад» и «Далее» с областью нажатия не менее 44×44 CSS px и номер страницы, вертикально отцентрированный между ними. В пределах одного ряда элементы SHALL иметь согласованные отступы и не перекрываться; на узком экране и при 200% текста SHALL оставаться читаемыми и доступными без горизонтального переполнения. Переход, состояния загрузки и запрета предыдущей/следующей страницы SHALL сохранять корректность.

#### Scenario: Одна страница
- **WHEN** ADMIN видит первую и последнюю страницу пользователей
- **THEN** обе кнопки недоступны, номер страницы выровнен между ними, а размеры и отступы компактны

#### Scenario: Несколько страниц
- **WHEN** ADMIN переходит на следующую и возвращается на предыдущую страницу клавиатурой
- **THEN** номер и список соответствуют выбранной странице, крайние переходы недоступны и фокус различим

#### Scenario: Узкий экран
- **WHEN** навигация показана на ширине 320 CSS px либо при увеличении текста до 200%
- **THEN** все элементы доступны и не обрезаны, без горизонтального переполнения страницы
