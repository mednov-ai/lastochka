## Context

Причина изменения — в proposal.md. Черновик: `docs/design/living-landing-2026-11-24/` (`index.html`, `motion.css`, `motion.js`, две видеозаписи). Он показывает вид и темп, но его код работает со снимком DOM и в продукт не копируется целиком.

Сейчас `useLandingMotion` пишет `--progress` и `--item-progress` для трёх `data-motion`. Страница формируется на сервере, расписание приходит отдельным потоком через `Suspense`. Тексты редактируются, состав и порядок блоков могут меняться.

## Goals / Non-Goals

**Goals:** один запоминающийся приём (лента), остальное движение ему подчинено. Текст читается без ожидания. Без JavaScript и при уменьшенном движении страница завершена.

**Non-Goals:** захват прокрутки, закреплённые сцены, звук, курсорные эффекты вне первого экрана, движение в кабинете и форме заявки.

## Decisions

### Выбранный подход

| Вариант | За и против |
|---|---|
| **А. Лента + раскрытия (выбран)** | Связан с гимнастикой и названием; требует маршрута для разных ширин |
| Б. Только раскрытия | Быстрее, но похоже на многие сайты |
| В. Видео | Самый живой вариант, но нет съёмки и согласий родителей |

Пользователь выбрал черновик с лентой, раскрытия из варианта Б включены. Видео остаётся возможным позже.

### Лента на canvas

Один `<canvas aria-hidden>` высотой 1,8 окна лежит внутри `main` между фонами разделов и содержимым. Он расположен в координатах документа, поэтому при прокрутке едет вместе со страницей и не отстаёт. Рисуется только видимая часть. SVG на всю страницу отклонён: у ленты переменная ширина и две стороны.

Фоны разделов переносятся в псевдоэлемент под лентой. Цвета берутся из действующих стилей, палитра не меняется. Карточки расписания и фотографии закрывают ленту.

### Маршрут от содержимого

Опорные точки вычисляются из геометрии существующих разделов, найденных по `id`. Отсутствующий раздел пропускается, порядок берётся из DOM. Наборы точек отдельные для ширин до 850 px и выше. Пересчёт — при изменении размеров, загрузке изображений, шрифтов и расписания. Положение ласточки определяет монотонная функция прокрутки; последняя точка достижима на нижней границе страницы. Значения в конкретных точках задаёт исполнитель по черновику с поправками:

- ласточка не рисуется поверх или под абзацами, ссылками и заголовками; точки маршрута через них недопустимы;
- рядом с текстом лента на компьютере и ласточка на всех ширинах плавно исчезают, поэтому запрет выполняется и для изменённых текстов;
- лента под текстом допустима на телефоне при контрасте текста не ниже 4,5:1 к обоим цветам ленты, для этого она там бледнеет;
- на телефоне лента не шире 11 px, на компьютере — 24 px.

### Покой

Покачивание затухает после 3 секунд без прокрутки, после чего `requestAnimationFrame` останавливается полностью. Скрытая вкладка не рисует. Кнопки паузы не нужны: самостоятельное движение короче 5 секунд после действия посетителя. Вступление на первом экране длится 2,4 секунды.

### Первый экран без мигания

Вступление заголовка и фото — CSS `@keyframes` под `prefers-reduced-motion: no-preference`, без ожидания JavaScript. Конечное состояние — обычные стили. Остальные раскрытия включает JavaScript и только для элементов ниже окна в момент включения; всё, что уже видно или выше, остаётся раскрытым. Фокус внутри скрытого элемента раскрывает его сразу.

Слова заголовков оборачивает React при рендере, чтобы не менять DOM вслед за ним; пробелы между словами сохраняются, доступное имя заголовка не меняется. Задержка зависит от порядка слова, номер строки не вычисляется.

### Фигуры возрастов

Пять SVG-поз растут слева направо. Подписи — активные направления из уже загружаемого ответа афиши, без нового запроса. При числе направлений от 1 до 7 рисуется столько же фигур, позы повторяются. Пока данных нет, при сбое и при другом числе показываются пять поз без подписей. Рисунок декоративный (`aria-hidden`), возрасты доступны в афише. Описания направлений не возвращаются: их убрали по правкам Паргева. Черновые фигуры перерисовываются: единая толщина, читаемые позы, без наложений. На компьютере рисунок справа от текста, на телефоне под ним.

### Остальные раскрытия

| Место | Приём | Длительность |
|---|---|---|
| Заголовки h2 | Строки из-под маски | 0,95 с |
| Фото форматов | Маска слева, снизу, справа; кадр после раскрытия целый | 1,1 с, шаг 0,16 с |
| Цены | Прочерчивание линии, затем сумма; цифры не «накручиваются» | до 1,05 с |
| Расписание | Волна времени по дням, заменяет подъём на 16 px | 0,55 с, шаг 0,07 с |
| Фото тренера | Маска снизу | 1,2 с |
| Цитата тренера | Слова проявляются по прокрутке | — |

## Risks / Trade-offs

- [Лента мешает читать] → запрет маршрута под текстом на компьютере, замер контраста, проверка на 320, 390, 768, 1024, 1440, 1920 px.
- [Рывки на слабом телефоне] → прежний бюджет: p95 ≤ 32 мс и ≤ 1% интервалов больше 50 мс при CPU ×4; при превышении сначала уменьшить число отрезков, затем отключить покачивание.
- [Фото первого экрана позже станет видимым] → сравнить LCP до и после на одной машине; ухудшение больше 200 мс не принимается.
- [Расписание приходит позже и сдвигает маршрут] → пересчёт без скачка ласточки: её положение плавно догоняет новую цель.
- [Редактор изменил тексты или скрыл блок] → проверки с длинным текстом, скрытым и переставленным блоком.
- [Замер на машине разработчика не заменяет телефон] → физический телефон указывается как отдельная приёмка.
