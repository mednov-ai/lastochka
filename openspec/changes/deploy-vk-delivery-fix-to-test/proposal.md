## Why

Исправленный разбор ошибок ВКонтакте есть только локально. На test, по отчёту от 22.11.2026, фоновая отправка выключена, backend находится только во внутренней сети и ключ сообщества не задан, поэтому одна новая сборка не доставит заявку в беседу.

## What Changes

- Собрать и выпустить на test новые backend и frontend с исправленным разбором ошибок. Схема остаётся V34, миграций нет. Новый frontend сохраняет ленту на главной, выпущенную в 0.27.0.
- Закрепить в требованиях автоматический повтор временной ошибки получателя и отдельную причину отказа, не связанного с беседой.
- Дать test backend исходящий доступ только к `api.vk.com:443` через отдельный ретранслятор. Прямого выхода в интернет у backend по-прежнему нет.
- Включить на test обработчик ВКонтакте. Push остаётся выключенным: VAPID не задаётся.
- Перенести настройки ВКонтакте для test из неотслеживаемого каталога выпуска в репозиторий, чтобы следующий выпуск их не потерял.
- Принять доставку: владелец вводит ключ и подтверждает тестовое сообщение, затем одна синтетическая заявка приходит в закрытую беседу.

Production, push при закрытой вкладке, Альфа-Банк и изменение схемы в объём не входят.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `vk-enquiry-notifications`: классификация ошибки получателя, автоматический повтор временных сбоев и понятная причина постоянного отказа.
- `isolated-production-and-test`: ограниченный исходящий доступ test к API ВКонтакте при включении канала.

## Impact

- Backend `notifications` и `common`, словарь ошибок кабинета. Исправление уже реализовано и проверено локально.
- `compose.isolated.yaml`, отдельный файл настроек test и конфигурация ретранслятора в `infra/`.
- На сервере заменяются test backend и frontend и добавляется один контейнер ретранслятора. PostgreSQL, gate, прокси, Nginx и production не пересоздаются.
- Внешняя система: API ВКонтакте. Сообщение содержит номер заявки и защищённую ссылку.
- Связано с открытой задачей 4.3 архивного `replace-telegram-enquiry-notifications-with-vk`.
