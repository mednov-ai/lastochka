## ADDED Requirements

### Requirement: Ограниченный исходящий доступ канала ВКонтакте

При отдельном включении канала ВКонтакте backend зоны SHALL обращаться наружу только к API ВКонтакте по HTTPS с проверкой сертификата исходного сервера. Прямой выход backend в интернет и обращение к другим внешним узлам SHALL оставаться недоступными. Промежуточный узел SHALL передавать шифрованное соединение без расшифровки и быть недоступным извне сервера. Включение канала в test SHALL сохранять состояние push, банковской интеграции и production. Настройки канала SHALL храниться в отслеживаемой конфигурации без секретов.

#### Scenario: Обращение к API ВКонтакте

- **WHEN** на test включена отправка ВКонтакте
- **THEN** backend устанавливает проверенное HTTPS-соединение с API ВКонтакте, а ключ сообщества не виден промежуточному узлу

#### Scenario: Другой внешний адрес

- **WHEN** процесс в сети test backend обращается к другому внешнему узлу напрямую или через промежуточный узел
- **THEN** соединение не устанавливается

#### Scenario: Следующий выпуск test

- **WHEN** оператор готовит следующий выпуск из репозитория
- **THEN** настройки и подключение ключа шифрования ВКонтакте входят в проверяемую конфигурацию выпуска

#### Scenario: Отключение отправки

- **WHEN** оператор возвращает выключенный обработчик или останавливает промежуточный узел
- **THEN** заявки продолжают сохраняться, неотправленные задания остаются в очереди либо получают видимую причину отказа
