## Why

Форма заявки перегружена: переключатель «Для ребёнка / Для себя», числовой возраст и
развёрнутый подбор занятия с шестью кнопками навигации. Каждое действие подбора
отправляет форму на сервер и возвращает страницу в начало, поэтому посетитель не видит
результата и считает, что выбор занятия не работает (воспроизведено на test 13.11.2026).
Студия при этом ведёт расписание по возрастным направлениям из справочника, а заявка
их не использует. Кроме того, на test ещё не было ни одной заявки и ни одного задания
уведомления, поэтому доставка администратору (Telegram и browser push) не доказана.

## What Changes

- Новая форма заявки: имя, телефон, **обязательная возрастная категория** из активных
  направлений справочника (3–5, 6–7, 8–9, 10–13, 14+), необязательное имя занимающегося
  и комментарий. Переключатель «Для ребёнка / Для себя» и числовой возраст из новой формы
  убираются; 14+ покрывает подростков и взрослых.
- Выбор занятия по умолчанию свёрнут («Удобное занятие — необязательно»). При раскрытии
  показывается короткий список ближайших доступных занятий **только выбранной категории**;
  выбор не перезагружает страницу и не сбрасывает прокрутку при работающем JavaScript,
  без JavaScript остаётся работающим серверный путь.
- Переход с карточки афиши по-прежнему предвыбирает занятие и его категорию; ссылки
  «Оставить заявку» в строках возрастных категорий афиши предвыбирают категорию.
- Заявка сохраняет снимок выбранной категории (идентификатор, подпись и границы на момент
  отправки); Telegram-сообщение и админка показывают категорию. Push по-прежнему без
  персональных данных.
- Новый контракт заявки (версия 3) с обязательной категорией; **прежний контракт версии 2
  продолжает приниматься** для ранее открытых форм и старого frontend на время выпуска.
  Прежние заявки читаются без изменений и без выдуманной категории.
- Приёмка уведомлений на test: проверка настройки бота и VAPID, включение обоих каналов,
  синтетическая заявка и подтверждение доставки в Telegram-чат и на подписанное устройство
  администратора; выявленные неисправности доставки исправляются в рамках изменения.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `enrollment-requests`: состав гостевой формы (категория вместо типа участника и возраста),
  свёрнутый и отфильтрованный по категории выбор занятия, отображение категории в админке.
- `telegram-notifications`: сообщение о заявке содержит выбранную возрастную категорию.

## Impact

- Frontend: `frontend/app/routes/enquiry.tsx`, `frontend/app/api/enquiry.server.ts`,
  ссылки на заявку на главной, админский список заявок, стили формы, браузерные тесты.
- Backend `enquiries`: DTO и проверка контракта версии 3, сохранение снимка категории,
  чтение активных направлений через контракт владельца справочника (scheduling),
  тексты Telegram в `user-messages.properties`; OpenAPI и сгенерированный клиент.
- БД: аддитивная миграция V29 (столбцы снимка категории в `enrollment_requests`);
  прежние строки не изменяются.
- Поставка: сначала backend (принимает версии 2 и 3), затем frontend; production — только
  по отдельной отмашке. Для проверки Telegram на test могут понадобиться токен бота и чат
  от пользователя и операторский доступ к env.
